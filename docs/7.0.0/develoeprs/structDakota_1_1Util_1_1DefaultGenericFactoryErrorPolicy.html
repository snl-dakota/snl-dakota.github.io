template<typename Key, typename CreateFun>
struct Dakota::Util::DefaultGenericFactoryErrorPolicy< Key, CreateFun >

The default error policy for GenericFactory. This error policy will return a default-constructed value of the same type as the CreateFun's return type in the case of error.

Template Parameters
Keythe lookup key; any hashable type is allowed
