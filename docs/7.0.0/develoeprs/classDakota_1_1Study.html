Detailed Description

Owns runtime services and factories for a library-mode study.

Construct variables, responses, interfaces, models, and methods from the leaves inward, then pass the top-level Iterator to run(). The Study must outlive every component constructed from it. Components from different Study instances may have incompatible runtime services and must not be combined.
