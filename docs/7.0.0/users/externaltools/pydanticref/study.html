Complete Dakota study specification

A Dakota study consists of: - environment (optional): Execution environment settings - method (required): One or more iterative algorithms - model (optional): One or more model configurations (surrogate, nested, etc.) - variables (required): One or more variable specifications - responses (required): One or more response function definitions - interface (optional): One or more simulation interface configurations

Each section can have multiple instances to support advanced Dakota workflows.

The method and model fields support three input styles: 1. Dict with discriminator: method=[{“sampling”: {“samples”: 10}}] 2. Selection instance: method=[SamplingSelection(sampling=SamplingConfig(samples=10))] 3. Bare config (auto-wrapped): method=[SamplingConfig(samples=10)]
