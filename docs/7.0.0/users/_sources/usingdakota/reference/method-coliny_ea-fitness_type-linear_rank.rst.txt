"""""""""""
linear_rank
"""""""""""

Set selection scaling

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* true

**Description**

The ``linear_rank`` setting uses a linear scaling of probability of
selection based on the rank order of each individual's objective
function within the population
