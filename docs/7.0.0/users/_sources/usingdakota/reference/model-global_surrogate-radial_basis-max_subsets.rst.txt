max_subsets
"""""""""""

Number of trial RBF subsets

**Topics**

:ref:`surrogate_models <topic-surrogate_models>`

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* 0

**Description**

Number of passes to take to identify the best subset of basis
functions to use.  Defaults to the smaller of 3 * (
:dakkw:`model-global_surrogate-radial_basis-bases`) and 100.
