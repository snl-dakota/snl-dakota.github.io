"""""""""""
descriptors
"""""""""""

Labels for the variables

**Specification**

- *Alias:* wuv_descriptors
- *Arguments:* None
- *JSON argument key:* None

**Description**

The optional variable labels specification ``descriptors`` is a list of
strings which identify the variables.  These are used in console and
tabular output.

The default descriptor strings use a variable type-dependent root
string plus a numeric identifier.
