""""""""""""""
hess_tolerance
""""""""""""""

Parameter for the DILI MCMC algorithm in MUQ

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* 0.0001

**Description**

The lower bound on eigenvalues used to construct the low-rank approximation of the global expected Hessian. The default value is '1.e-4'.
