.. _method-sampling-tolerance_intervals-confidence_level:

""""""""""""""""
confidence_level
""""""""""""""""

The confidence level to be used to determine the standard deviation
of the equivalent normal distribution.

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* 0.9

**Description**

The confidence level must be a value between 0 and 1.

*Default Behavior*

A value of 0.90 (90%) is the default value for this parameter.

**Examples**

.. tab:: Freeform

   .. code-block:: dakota

       method
         sampling
           samples 5
           refinement_samples 4 3 3
           sample_type random
           tolerance_intervals
             coverage 0.96
             confidence_level 0.92
           seed = 31415

.. tab:: JSON

   .. code-block:: json

       {
         "method": [
           {
             "sampling": {
               "samples": 5,
               "refinement_samples": [4, 3, 3],
               "sample_type": {"random": true},
               "tolerance_intervals": {
                 "coverage": 0.96,
                 "confidence_level": 0.92
               },
               "seed": 31415
             }
           }
         ]
       }
