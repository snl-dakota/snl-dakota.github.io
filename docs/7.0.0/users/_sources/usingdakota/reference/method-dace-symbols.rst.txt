.. _method-dace-symbols:

"""""""
symbols
"""""""

Number of replications in the sample set

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* 0

**Description**

``symbols`` is related to the number of levels per variable in the sample
set (a larger number of symbols equates to more stratification and
fewer replications).  For example, if symbols = 7, each variable would be
divided into seven levels.
