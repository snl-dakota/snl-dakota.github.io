betas
"""""

Parameter of the exponential distribution

**Specification**

- *Alias:* euv_betas
- *Arguments:* None
- *JSON argument key:* None

**Description**

Specifies the list of :math:`\beta`  parameters to define the distributions of the exponential random variables. Length must match the other parameters and the number of exponential random variables.
