Grid Sampling

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* true

**Description**

The grid option in DACE will produce a randomized grid of points.
If you are interested in a regular grid of points, use
the multidimensional parameter study (under Parameter Studies) instead.
