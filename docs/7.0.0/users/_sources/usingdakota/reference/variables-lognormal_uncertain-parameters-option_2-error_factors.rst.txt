error_factors
"""""""""""""

Second parameter of the lognormal distribution (option 2)

**Specification**

- *Alias:* lnuv_error_factors
- *Arguments:* None
- *JSON argument key:* None

**Description**

For the lognormal variables, one may specify the mean :math:`\mu` and error factor :math:`\epsilon`  of the actual lognormal distribution.

This specifies the error function of the lognormal random variable.
