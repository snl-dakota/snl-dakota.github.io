**Description**

This keyword group is used to select from among the supported
results file formats.

*Default Behavior*

By default, the `dakota` format is used.

**Examples**

.. tab:: Freeform

   .. code-block:: dakota

       interface
         fork
         analysis_drivers 'driver.py'
         parameters_file = "params.in"
         results_file = "results.out"
         results_format
           json

.. tab:: JSON

   .. code-block:: json

       {
         "interface": [
           {
             "analysis_drivers": {"drivers": ["driver.py"]},
             "interface_type": {"fork": {}},
             "parameters_file": "params.in",
             "results_file": "results.out",
             "results_format": {"json_format": {}}
           }
         ]
       }
