"""""""""""
output_file
"""""""""""

Base filename for output redirection

**Topics**

- :ref:`dakota_IO <topic-dakota_IO>`
- :ref:`command_line_options <topic-command_line_options>`

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None

**Description**

Specify a base filename to which Dakota output will be
directed.  Output will (necessarily) be redirected after the input
file is parsed.  This option is overridden by any command-line -output
option.

*Default Behavior*

Output to console (screen).
