.. _method-efficient_global-x_conv_tol:

""""""""""
x_conv_tol
""""""""""

x-convergence tolerance

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* -1.0

**Description**

The Efficient Global Optimization method will terminate if the
relative change in the best decision variables values x is less than
the specified tolerance.
