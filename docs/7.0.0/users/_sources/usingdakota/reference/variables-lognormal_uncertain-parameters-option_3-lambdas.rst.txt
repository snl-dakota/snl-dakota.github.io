lambdas
"""""""

First parameter of the lognormal distribution (option 3)

**Specification**

- *Alias:* lnuv_lambdas
- *Arguments:* None
- *JSON argument key:* None

**Description**

For the lognormal variables, one may specify the mean
:math:`\lambda`  ("lambda")
and standard deviation
:math:`\zeta`  ("zeta")
of the underlying normal distribution.
