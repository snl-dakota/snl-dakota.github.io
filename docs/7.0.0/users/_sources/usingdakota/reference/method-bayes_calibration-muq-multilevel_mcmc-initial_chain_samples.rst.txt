initial_chain_samples
"""""""""""""""""""""

Number of initial samples for each level

**Topics**

:ref:`bayesian_calibration <topic-bayesian_calibration>`

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* 1000

**Description**

Set the number of samples taken at each level.

*Default Behavior*

Defaults to 100.

**Examples**

.. tab:: Freeform

   .. code-block:: dakota

       method,
       bayes_calibration muq
         chain_samples = 1000
         multilevel_mcmc
           initial_chain_samples = 50
           target_variance = 0.5
           subsampling_steps = 12 0
           greedy_resampling_factor = 0.5

.. tab:: JSON

   .. code-block:: json

       {
         "method": [
           {
             "bayes_calibration": {
               "sub_method": {
                 "muq": {
                   "chain_samples": 1000,
                   "mcmc_algorithm": {
                     "multilevel_mcmc": {
                       "initial_chain_samples": 50,
                       "target_variance": 0.5,
                       "subsampling_steps": [12, 0],
                       "greedy_resampling_factor": 0.5
                     }
                   }
                 }
               }
             }
           }
         ]
       }
