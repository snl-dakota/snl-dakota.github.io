recommended_points

Construct surrogate with recommended number of points

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* true

**Description**

This is the default option.  It requires 5*d build points for d input
dimensions, except for polynomial models.  See parent page.
