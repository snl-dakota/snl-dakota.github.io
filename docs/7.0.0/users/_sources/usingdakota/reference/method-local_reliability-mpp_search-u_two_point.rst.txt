u_two_point
"""""""""""

Predict MPP using Two-point Adaptive Nonlinear Approximation in "u-space"

**Topics**

:ref:`reliability_methods <topic-reliability_methods>`

**Specification**

- *Alias:* None
- *Arguments:* None
- *JSON argument key:* None
- *Default:* true

**Description**

This mpp_search option is identical to ``x_two_point``, but it performs the
Two-point Adaptive Nonlinear Approximation (TANA) in u-space instead of x-space.
