Detailed Description

Describes the active variable view an iterator wants for its iterated model when constructed through the DI (IRStore) path.

The request is resolved against the model inside Iterator::assign_requested_view() before update_from_model() is called. Only the DI constructors use this type; legacy ProblemDescDB constructors are unaffected.

responseRule: when true (the default), the "objective functions or calibration terms → DESIGN" precedence rule is applied before the spec. NonDBayesCalibration passes responseRule=false to prevent calibration terms from flipping to DESIGN.
