Detailed Description

Read-only view of specification data from either a ProblemDescDB or a block-local IRStore, so constructors can share one body across the legacy and DI paths.

Keys use the ProblemDescDB form ("model.surrogate.nugget"); for an IRStore the block prefix is stripped ("surrogate.nugget"). Keys absent from the store yield a value-initialized T, matching the defaults the ProblemDescDB path supplies for unspecified keywords.
